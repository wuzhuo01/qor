# 证据边界

Evidence Source 是治理元数据。它不是主张为真的证明。

产物带有证据项。每一项有来源类别（`kind`）、定位符和生产者。一条发现可以标明主张类别。评审用这些字段判断：所声明的来源是否允许支持这一类主张。

## QOR 检查什么

QOR 检查三件事：

- 证据来源类别是 `reasoning`、`external`、`tool` 或 `human` 之一。已经保存的旧标签仍可加载。未知类别会被拒绝。
- 主张与证据是否匹配。发现写明主张如何分类。评审把这个类别和所引用证据的 `kind` 比较。
- `reasoning` 没有被当成事实。引用 `reasoning` 的事实主张，评审失败。`reasoning` 可以支持假设、推测或研究方向。

`kind` 由产出该产物的 Agent 写入。运行时把这份声明原样复制到产物上。它不会改写成运行时自己观察到的来源。

## QOR 不检查什么

QOR 不检查：

- `external` 数据是否真实。
- `tool` 是否真实执行过。
- 定位符是否对应现实世界中的资源。

定位符必须非空，这样后来的读者能看见生产者指向哪里。运行时不会抓取、执行这个定位符，也不会拿它和某次工具记录对照。V1.0 没有可对照的工具执行记录。

因此，`external`、`tool` 和 `human` 可以在没有相应观察的情况下被声明。未填写主张类别时，不执行“推理被当成事实”这项检查。

## 是元数据，不是证明

Evidence Source 记录组织如何分类一条主张的支撑。它让评审拒绝只靠生产者自身推理来支撑的事实。

它不证明某条外部陈述发生过，不证明工具返回了所引用的结果，也不证明定位符可以打开。评审通过，表示所声明的来源类别允许支撑这一主张类别。它不表示主张为真。

## 不属于 V1.0

以后的版本可以核验 `external` 和 `tool` 的来源：把声明的来源绑到一次实际获取，或一次有记录的工具运行。

这项检查不属于 V1.0。V1.0 把来源类别保持为声明的元数据，并执行上面的主张类别规则。
