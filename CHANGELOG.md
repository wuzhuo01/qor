# Changelog

## V1.0

- Established the generic AI-native organization runtime core.
- Added capability-based assignment.
- Added review, synthesis, decision, and human responsibility.
- Added a governed action and verification path. Execution of an action is not settlement.
- Added scheduler and event-router task creation. Neither executes the task.
- Established the V1.0 core contract and its evidence boundaries.
- The generic profile intentionally has no domain business capabilities.
- A public neutral business example is intentionally not included, because the generic profile does not provide domain capabilities. The organization runtime demo is included: `python -m examples.organization_runtime`.
